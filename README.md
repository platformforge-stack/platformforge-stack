## The idea

I am one developer who likes open source and wanted to test a simple question:

> If a single person commits fully to one project for six months, does it leave a measurable mark?

So this account is an experiment, not a portfolio. Every six months I pick one
open-source project, go deep, and contribute as much as I usefully can: reading
the codebase, fixing bugs, hardening security, writing docs, cleaning up
tooling, and opening focused pull requests. At the end of the cycle I look back
and ask whether any of it made a difference, for the project and for me.

I deliberately target projects with **great potential but a small community**:
solid, genuinely useful software that simply does not have many hands on it. That
is where one focused contributor is most likely to leave a visible dent, and where
the whole question gets its most honest test.

Honest framing: these are independent community contributions. I am not
affiliated with the maintainers of any project I work on, and nothing here is
official. The goal is to help and to learn in the open.

## How a cycle works

| Phase | Roughly | What happens |
|------|---------|--------------|
| **Explore** | weeks 1 to 2 | Read the code end to end, map the architecture, find the real pain points |
| **Contribute** | weeks 3 to 22 | Focused PRs: bugs, security, docs, tests, tooling. One concern per PR |
| **Measure** | final weeks | Count what landed, what got reviewed, what stuck. Write it up honestly |

Rules I hold myself to:
- One concern per pull request, small enough to review.
- Follow the project's own conventions over my preferences.
- Security issues go through private, coordinated disclosure, never public PRs.
- Report outcomes as they are, including the PRs that got rejected.

## Season 01: MelisPlatform

MelisPlatform is an open-source CMS and ecommerce platform written in PHP on top of the Laminas framework (formerly Zend Framework), with a back office that mixes legacy tooling and a newer React interface. It is modular: `melis-core` is the
foundation (users, rights, the back office, tooling), and separate modules add the CMS, commerce, templating, and more. This season is spent inside that ecosystem.
